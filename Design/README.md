# Echo 视觉系统接入

Echo v0.2.0（build 2）使用原创耳廓狐、几何字标、生活场景插画和珊瑚橙／靛蓝／奶油色视觉系统。

## 设计依据

- [Echo 视觉规范 v1.0](Echo-Visual-Spec-v1.0.md)：品牌、角色、原生布局、排版、录音状态、隐私和无障碍要求。
- [tokens.json](tokens.json)：语义色、品牌色、字体层级、间距、圆角、描边和动效的数值源。
- [运行资产](../Echo101/Assets.xcassets)：App 图标、Logo、六种角色状态、四个生活场景插画和语义 Color Set；随原生工程编译。

仓库保留完整规范与 tokens，只复制 App 运行所需的图片和颜色资产。设计稿、原生截图和运行资产分别承担设计依据、渲染证据和运行显示，不互相替代。

## 原生页面映射

| ID | 页面 | 主要设计要求 |
| --- | --- | --- |
| VIEW-01 | Today | 欢迎角色、一个活动主入口、主动复习、固定家长入口 |
| VIEW-02 | Explore | Toys / Food / Get ready / Bedtime；插画识别，辅助功能大字改单列 |
| VIEW-03 | Listen & Say | 英文与释义、Listen / Slow / Parts、明确启动的跟说录音与跳过 |
| VIEW-04 | My World | 家庭场景与可追溯使用记录，不展示掌握率或排名 |
| VIEW-05 | Overview | 下一次可共同使用的表达；记录数量不代表能力 |
| VIEW-06 | Add a Moment | 先文字再场景；可选录音；本地保存与云端请求分开 |
| VIEW-07 | Review an Expression | 明确 Draft、可编辑字段、Confirm Expression 与 Keep as Draft 分开 |
| VIEW-08 | Privacy & Settings | 麦克风、云端、提醒、录音管理、导出恢复与删除后果 |

儿童导航为 Today / Explore / My World；家长导航为系统认证后的 Overview / Moments / Settings。家长区和儿童区共享品牌与语义色，但保留不同的信息密度。

## 接入约定

- 使用浅色／深色语义颜色，不把插画品牌色直接用于正文。珊瑚按钮用靛蓝字，靛蓝主按钮用高对比文字。
- 页面水平边距 24pt，输入圆角 16pt、控件描边 1.5pt、卡片圆角 28pt；家长主要按钮至少 56pt，儿童主要动作至少 64pt。
- 标题使用圆角系统字体，正文使用系统字体；支持 Dynamic Type。输入标签始终可见，不用占位文字替代标签；不附带 Apple 字体文件。
- 角色插画保持原始几何比例，纯装饰图片不重复进入读屏焦点。减少动态效果时保留静态反馈。
- 界面文案默认英文；用户生活片段、中文释义与家长提示保留其内容语言。
- 录音、播放和处理状态明确分离；视觉更新不改变主动录音、家长确认、删除确认或云端发送边界。

## 复核

八个关键页面、深色和大字样例见 [原生页面截图与验收清单](../docs/ACCEPTANCE.md#原生页面截图)。截图仅证明渲染结果，不证明真实点击、系统认证、音频或模型服务成功。

视觉规范中 110 个设计页面／状态版本的检查结果属于设计包，不能标记为 App 的 110 项原生实现或验收。当前 App 接入的是上述八个关键页面及运行所需资产；最大辅助功能字号、VoiceOver、键盘、音频中断和系统图标效果仍需设备验收。
