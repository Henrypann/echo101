# Echo 品牌与 iOS 视觉规范

**v1.0 · 2026.09.30 · Brand & Interface System**

> 把每天的小事，变成一起说出的英语。

Echo 是面向 2–5 岁亲子家庭的生活英语伙伴。以真实生活为素材，通过听示范、一起说和再次使用，让表达与经历联系起来。品牌的核心是“我在听，我们一起试”，不是考试、连续打卡或能力排名。

## 01 品牌原则

| 原则 | 视觉与行为要求 |
| --- | --- |
| 先回应，再引导 | 角色面向孩子；每页一个主要动作；收到操作后立即给予清晰反馈 |
| 鲜明但不喧闹 | 珊瑚橙与靛蓝建立对比；大面积奶油底；单个场景最多使用三个装饰色 |
| 儿童易操作，家长易理解 | 同一品牌，两种信息密度；儿童依赖图形与示范，家长依赖记录、状态和操作说明 |
| 结束也是好体验 | 活动结束后鼓励线下实践；不自动续播，不制造断签损失或角色失落 |
| 记住经历，不定义孩子 | 只展示可追溯的接触和使用记录；没有“智力”“性格”“英语水平百分比” |

儿童区对 2–3 岁由家长主导；3–5 岁允许在陪同下点按。低龄用户不需要阅读菜单才能完成核心活动。

## 02 Logo 系统

### 2.1 主品牌

耳廓狐头像是 Echo 的识别主体，与小写 `echo` 字标组成标准品牌。公开展示名称使用 **Echo**；视觉字标固定为小写 **echo**。不混用 Echo101 作为用户界面中的品牌字标。

头像特征为大耳朵、圆润短吻、奶油面颊、靛蓝五官。两耳呈轻微不同的倾角，左耳内有折叠形状；脸部奶油面形成左右呼应的曲线。角色不佩戴耳机、麦克风或博士帽，避免将品牌限制成录音工具或学校教育。

### 2.2 组合与尺寸

| 形式 | 使用场景 | 最小显示宽度 |
| --- | --- | --- |
| 头像图形标 | App 内品牌点、头像、社交标记 | 32pt；24pt 使用简化版 |
| 简化头像 | 小标签、通知中的装饰标记 | 24pt；更小时改用通用功能图标 |
| echo 字标 | 启动页、文档和品牌署名 | 88pt |
| 横向组合 | 文档页眉、品牌落款 | 160pt |
| 纵向组合 | 品牌封面、启动展示 | 120pt |

保护空间以头像 320×320 绘图板中的 **40 单位为 1U**。头像四周至少 1U；字标及组合四周至少为字标 x-height 的 1/4。图形和字标的相对位置固定，使用完整组合文件，不自行拼接。

字标由原创几何路径构成，不是将系统字体直接打出。字符的曲线、开口和字距都是品牌资产的一部分；不要用相似字体替换。

### 2.3 色彩版本

- 彩色头像用于奶油底、白底或深靛蓝底；复杂图片上先放置纯色容器。
- 单色版使用靛蓝实色与透明负形，适合印刷及低色数场景。
- 反白版使用白色实色与透明负形，适合深色背景。
- 功能按钮上的状态图标使用语义色；Logo 不承担成功、警告或失败状态。

### 2.4 错误用法

禁止拉伸、旋转整体 Logo、调整五官位置、改动耳朵比例、加外发光、裁掉耳尖、重排字标、给字标加渐变，或放在没有足够对比度的照片上。不要将角色表情变化作为不同品牌 Logo；正式字标组合固定使用欢迎表情。

## 03 耳廓狐角色

### 3.1 造型基准

头像使用 320×320 坐标系；全身角色使用 360×400 坐标系。所有状态共享同一耳朵、头部、面颊、鼻子和身体路径。头部是主要识别面积，身体保持小而稳定，尾巴有奶油色末端。

- 主体：Coral；内耳与脚：Coral Deep；面颊和腹部：Cream；眼睛与鼻子：Indigo。
- 眼睛不增加写实高光、渐变虹膜或睫毛；性别中性。
- 短吻、圆角四肢、不露尖牙；不增加物种之外的角或翅膀。
- 插画是平面几何造型，最多使用单级硬边阴影。禁止混入写实毛发或 3D 塑料质感。

### 3.2 标准姿态与六种状态

| 状态 | 表现 | 适用位置 | 行为边界 |
| --- | --- | --- | --- |
| Welcome / 欢迎 | 睁眼微笑，一只手抬起 | 首页、首次进入 | 不自动播放声音 |
| Listening / 倾听 | 手靠耳朵，外侧两道回声弧 | 明确启动的录音状态 | 必须同时显示麦克风、文字、计时和停止按钮 |
| Demonstrate / 示范 | 圆形开口，向前示意 | 播放示范和重听 | 不叠加录音指示 |
| Waiting / 等待 | 平静表情，双手靠近身体 | 等待输入或短时处理 | 处理状态需配文字及取消；不让角色焦虑 |
| Encourage / 鼓励 | 弯眼微笑、双手抬起 | 完成一次尝试 | 奖励参与，不宣称已掌握 |
| Goodbye / 告别 | 挥手、放松微笑 | 活动结束 | 不哭泣、不挽留、不自动进入下一项 |

全身标准姿态采用 Welcome。正式头像与 App 图标保持 Welcome，不随日常运营替换为哭脸或生气表情。

### 3.3 动效与声音

按下反馈 120ms，页面状态切换 220ms，角色反馈 480ms；一次庆祝最长 900ms，不循环。角色动作以耳朵轻转、手臂挥动和表情切换为主，整体位移不超过容器高度的 6%。

开启“减少动态效果”后，使用静态姿态与文字替换所有弹跳、缩放、视差和脉冲。声音不是唯一状态反馈；不自动播放欢迎语。录音开始／结束可提供一次轻触觉反馈，不使用连续震动。

## 04 App 图标

主图标采用奶油底上的耳廓狐头像；深色图标使用靛蓝底；单色适配使用明确的正形与负形。主体位于画布中部，耳尖、脸部和五官不触及系统裁切区域。

- 母版为 1024×1024；输出文件不预烘焙圆角、不附加外部投影、不在角落放文字。
- 背景与前景分层源文件分别交付。最终合成的普通 PNG 为不透明画布；前景层允许透明。
- 预览包含 24、32、60、120、180 和 1024 像素，另附系统圆角裁切示意。
- 深色与单色是独立审阅版本，不只是给彩色版自动套滤镜。
- 当前系统的 clear / tinted 外观由平台合成。分层 SVG 是设计输入，不等于已编译的 Icon Composer `.icon` 工程；接入 App 时需在当前 Xcode 校验系统效果。

## 06 字体与排版

正式 iOS 实现使用系统字体：标题采用圆角设计的 SF Pro，正文采用 SF Pro，中文回退 PingFang SC。不要随交付包分发 Apple 字体文件。Logo 不依赖这些字体。

| 样式 | 字号／行高 | 字重 |
| --- | --- | --- |
| childTitle | 30 / 36 | 800 |
| childHeading | 24 / 30 | 700 |
| childBody | 20 / 28 | 600 |
| childLabel | 16 / 22 | 700 |
| parentTitle | 28 / 34 | 750 |
| parentHeading | 20 / 27 | 700 |
| parentBody | 17 / 25 | 400 |
| caption | 13 / 19 | 600 |
| button | 18 / 24 | 700 |

- 儿童核心表达至少 20pt；短标题 30pt；辅助标签不能成为完成任务的唯一信息。
- 家长正文 17pt，辅助信息 13pt；安全、权限和删除说明不能缩到脚注隐藏。
- 标题和按钮支持换行。正文不使用固定高度，不截断重要操作，不通过缩小字体解决空间不足。
- 使用 iOS Dynamic Type：正文、标签和按钮随用户设置增长；大字时双列卡片改为单列，横向操作改为纵向。
- 顶部系统时间及底部图标导航在本设计图中保持固定。实际产品在辅助功能字号下为导航提供系统大内容查看与 VoiceOver 标签，不能要求读取 12pt 标签才能导航。
- 交付中的 SVG 页面为跨工具可查看的设计稿，使用系统可用的 Arial / PingFang 回退。实际 SF Pro 字形和 Dynamic Type 行为需在 iPhone 实现时复核；200% 是设计压力样例，不是对真实 iOS 行为的冒充。

## 07 布局、形状和层级

| 项目 | 规范 |
| --- | --- |
| 基础单位 | 4pt；常用间距 8 / 12 / 16 / 20 / 24 / 32 / 40 |
| 页面边距 | 左右 24pt；375、393、430pt 宽度均保留 |
| 卡片内边距 | 20–24pt；不同内容块至少 16pt |
| 圆角 | 输入 16pt、按钮 20pt、卡片 28pt、重点容器 36pt |
| 控件描边 | 1.5pt；功能图标 2.25pt；焦点 3pt |
| 卡片阴影 | 向下 5pt，无模糊，轻暖色；深色用更深背景，不发光 |
| 按钮阴影 | 向下 4pt；按下位移 3pt；减少动态效果时直接换静态样式 |
| 儿童操作区 | 主要按钮至少 64pt 高；其他关键目标至少 56×56pt |
| 家长操作区 | 至少 44×44pt；主要按钮 56pt 高 |
| 页面层级 | 标题 → 当前任务 → 主要操作 → 辅助操作；每屏一个主要 CTA |
| 安全区 | 以系统 safe area 为准，图稿的状态栏尺寸不可硬编码到 App |

儿童模式底部导航为 Today / Explore / My World。家长模式为 Overview / Moments / Settings。模式切换位置固定：儿童右上角锁形入口，家长右上角返回儿童区。成人验证使用系统设备认证或家长设置的验证方式，不用简单数学题当作可靠认证。

iPad 保留同一套图形与变量；家长区可采用侧栏＋详情，儿童活动仍以一个主要任务居中。内容面板建议最大 640pt，场景浏览最多三列；不简单放大手机上的所有字号和按钮。此版不提供完整平板页面。

## 08 组件规范

| 组件 | 结构和默认尺寸 | 状态与无障碍 |
| --- | --- | --- |
| Primary button | Indigo＋白字；儿童 64pt、家长 56pt | default / pressed / disabled / processing；处理时保留动作文字 |
| Coral button | Coral＋Indigo 字；用于一个突出的活动 | 不与多个主按钮并列争抢注意力 |
| Secondary button | 白／surface 底＋controlBorder | 与主按钮保持至少 12pt 间距 |
| Icon button | 图形 24pt，目标 56pt／44pt | 必须提供动作标签；装饰图标不进入读屏焦点 |
| Bottom navigation | 三项，图标＋文本＋选中底形 | 提供 selected trait；不只换颜色 |
| Scene card | 插画＋场景名；小字时双列 | 整卡可点；大字改单列；卡片标签由 VoiceOver 朗读 |
| Expression card | 英文＋释义＋场景／接触状态 | 未确认候选标 Draft；不可在儿童区出现 |
| Audio player | Listen / Slow / Parts | 当前播放按钮切为 Pause；朗读文本与显示文本可不同 |
| Recorder | 麦克风＋Recording＋计时＋Stop | 明确点击才开始；停止后先预览，再主动保存 |
| Progress | 本次活动步骤或已接触内容 | 不展示未经验证的掌握百分比；不编码能力排名 |
| Sticker | 场景物品＋简短说明 | 庆祝后可关闭，不推动连续使用 |
| Input | 标签始终可见，至少 56pt 高 | placeholder 不代替标签；错误紧邻字段，焦点可到达 |
| Filter tag | 胶囊底、selected 图标 | 不仅颜色区分；点击区不少于 44pt |
| Notice | 图标＋标题＋可执行说明 | info / success / warning / danger；危险操作不只显示红色 |
| Dialog | 标题、后果、主次按钮 | 内容可滚动；取消始终可达；关闭后恢复触发点焦点 |
| Parent gate | 锁图形＋明确说明＋系统验证 | 验证失败返回儿童区；不暴露管理数据 |

所有组件的状态在语义上保持一致，不因页面风格变化改变颜色含义。HTML 手册的状态演示不采集声音、不调用模型、不保存家庭数据。

### 8.1 语音状态必须分离

| 状态 | 图标与文本 | 主操作 | 不能出现的行为 |
| --- | --- | --- | --- |
| Ready | 播放三角 / Ready to listen | Listen | 显示类似正在录音的持续波形 |
| Playing | 扬声器 / Playing example | Pause | 同时显示 Recording |
| Recording | 麦克风＋实心点 / Recording · 计时 | Stop | 隐藏时长、停止入口或退出后继续采集 |
| Processing | 静态时钟 / Processing | Cancel | 用麦克风脉冲暗示仍在录音 |
| Permission denied | 锁 / Microphone is off | Listen Instead / Ask an Adult | 阻止全部学习、反复索要权限 |

## 09 关键页面

### 9.1 Today

欢迎角色、当前活动、一个主按钮、一个复习入口。不同时出现多个奖励弹窗。家长入口固定在右上角；没有公开社交、排名或消费入口。

### 9.2 Explore

按 Toys / Food / Get ready / Bedtime 四个生活场景组织。卡片以物品插画识别，颜色辅助区分，不要求识字。大字样例改单列，内容按纵向流动。

### 9.3 Listen & Say

物品 → 英文 → 中文释义 → 听示范 → 慢速／语块 → 一起说。跳过始终可达；不播放刺耳的错误音。只显示家长已确认内容；有明确的非录音初始状态。

### 9.4 My World

呈现家庭场景和使用记录，标记 Heard together / Tried with help 等有依据的状态。没有满分、掌握率、比同龄人领先等结论。收藏入口用于再次遇见熟悉内容。

### 9.5 Overview

以“下次可以一起做什么”为中心。活动数量仅说明记录规模，不代表能力。精选建议连接回真实生活，不把孩子的完整对话逐字公开给所有家庭成员。

### 9.6 Add a Moment

先输入生活片段，再选场景。录音是可选且独立的操作。保存本地记录与向云端请求英语候选不是同一个按钮；不得在保存时顺便外发。

### 9.7 Review an Expression

Draft 状态醒目但不使用错误红色。英文、释义和语块均可编辑；家长明确确认后才进入儿童区。保留草稿和确认是不同操作。

### 9.8 Privacy & Settings

明示麦克风、云端、提醒、录音、导出和删除。关闭云端不影响本地播放。删除说明指出关联内容影响，不以模糊的“清理”替代。时长提醒是可调整的家庭偏好，不代表医疗或健康标准。

| --- | --- | --- |
| Empty | 欢迎而非责备，说明第一步 | 家长 Add a Moment |
| Offline | 保留已有内容和离线标记 | Play Saved Words；不自动重发 |
| Microphone denied | 明确权限状态，不把问题归因于孩子 | Listen Instead / Ask an Adult |
| Unclear speech | “I didn’t catch that.” | Listen Together / Skip for Now |
| Processing | 录音已停止，正在处理 | Cancel；完成仍待家长确认 |
| Finished | 微笑告别、鼓励线下活动 | Close Activity；再次听需主动操作 |

角色不能替代正文解释。等待、空态、失败都有明确的下一步；不存在只能等待自动跳转的死路。

## 11 可访问性与开发映射

### 11.1 读屏顺序

儿童页：页面标题 → 当前表达或活动 → 主操作 → 辅助操作 → 家长入口 → 底部导航。家长页：标题 → 状态 → 内容字段 → 主操作 → 次操作 → 导航。角色若纯装饰应隐藏读屏标签，不能每次都重复朗读“可爱的狐狸”。

| 元素 | 推荐 VoiceOver 标签 |
| --- | --- |
| Listen | Play the example: A red car. |
| Slow | Play the example slowly |
| Parts | Play the example in parts |
| Say It Together | Start a recording; recording begins after activation |
| Stop | Stop recording |
| Parent lock | Open parent area; adult verification required |
| Draft | Draft expression; not yet available in child mode |

录音或处理状态变化使用适量通知，不每秒朗读计时；停止后宣布“Recording stopped”。删除和权限变化需可感知的结果。关闭弹窗时恢复焦点。

### 11.2 设计变量接口

`tokens.json` 是唯一的数值源。颜色通过 `color.light` / `color.dark` 语义键使用；插画通过 `brand` 使用；不要把 `brand.coral` 当成正文文字色。尺寸单位为 pt，网页设计样例按 1 CSS px = 1pt 的布局基准表达，不代表物理像素相同。

| 设计语义 | 接入目标 |
| --- | --- |
| color.* | iOS 语义 Color / Color Set；按外观切换 |
| typography.styles | 系统字体及 Dynamic Type 语义样式 |
| spacing / radius / size | 布局与控件尺寸常量 |
| stroke / shadow | 图标与容器规则 |
| motion | 状态转场时长和减少动态效果分支 |
| assets/brand | 字标、图形和组合，不依赖字体 |
| assets/mascot | 六种标准状态，共享造型 |

本包提供设计变量，不引入新的业务 API，不改变数据结构、权限或 App 行为。将设计接入代码时，应保持录音、确认、删除及云端发送边界。
