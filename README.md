# Echo

老人用普通话说一句眼前正在发生的事，手机马上给出一句简单的英文并读出来。孩子跟着说，录音留在手机上，爸妈晚上再看。

**v0.3.0 · build 3 · iOS 17+**。只给自己家用，用免费 Apple ID 通过 Xcode 装到 iPhone。没有账号，没有服务器。目标机器是 iPhone XS（最高 iOS 18）。语音识别只用系统自带的 `SFSpeechRecognizer`（zh-CN，`requiresOnDeviceRecognition = true`），不用 iOS 26 才有的接口。

## 老人这一页

只有一个页面，三种状态，没有标签栏，也不用老人确认任何东西。

1. **等待**：中间偏下是一个大圆按钮，「按一下，说中文」。上面是上一句的中文意思和英文，点一下可以再听。
2. **正在听**：按钮变红，显示「正在听……」和秒数。轻点一下结束；安静大约 3 秒会自己停；最长 20 秒。开始时有一下轻震动和很短的提示音。
3. **结果**：最上面是这句英文自己的中文意思，下面小一点是老人刚才说的原话，然后是英文。三个通栏按钮：
   - **播放英文**：先慢读一遍，再按正常速度读一遍（美式英语）。
   - **孩子跟读**：再读一遍英文，然后为孩子录音约 10 秒，显示「录好了」。不打分。
   - **再说一遍**：回到正在听。

先在本机句库里找。对上了就直接读。对不上，并且爸妈已经同意、也填了 Key、网络允许，才会把**识别出的中文文字**发给 DeepSeek 或小米 MiMo。生成的句子可以先听，旁边有一行灰色「待爸妈确认」。它**不会**进句库，**不会**进每天轮换，也**不会**自动变成已确认。

没同意、没有 Key，或者网络不允许、模型失败时，不调用模型。屏幕写「这句先记下了，爸妈晚上补英文」，这句话会留下来。

听不清、太短、没识别出字：「没听清，请再说一遍」。麦克风、语音识别、普通话离线语音包有问题时：「请让爸妈看看手机」，并在爸妈区记一条待处理。

## 爸妈

右上角灰色「爸妈」**长按 3 秒**进入。上面的数字是待确认的句子，加上待处理的设置和超过 7 天没导出的提醒。进入不用 Face ID。Face ID 或设备密码**只**保护填写 API Key 的那一页。

离开 App 或切到后台，会回到老人这一页。

爸妈区可以：

- 并排看老人的原话、匹配或生成的英文、中文意思；播放老人原录音和孩子跟读。
- 确认或改生成的句子，给「爸妈晚上补英文」补上英文。确认之后才进入句库。句库里的句子也可以改、可以删。
- 看还没处理的权限和语音包问题。
- 看上次导出时间，导出或恢复。分享结束或关掉分享时，App 里的那份未加密副本会删掉；每次打开也会清空 `Exports/`。
- 选择模型、一次性同意、是否允许蜂窝数据、英文声音。

模型默认只走 Wi-Fi。打开「允许使用蜂窝数据」之后，没 Wi-Fi 也可以问模型。

## 爸妈一次性设置

这部手机用免费 Apple ID，经 Xcode 用数据线安装。免费签名大约 **7 天**过期，过期后 App 打不开，需要用同一台 Mac 再装一次。免费账号同时大约只能登记 **3 台**设备；名额满了，就在 Xcode 的设备列表里删掉不用的那台，再装。

Bundle ID 保持 `com.henrypann.echo101`，覆盖安装可以留下本机数据。装好之后建议马上导出一份。

1. **麦克风和语音识别**：第一次按录音时，系统会问两次。都选允许。这两次弹窗期间不用再按第三下。
2. **普通话离线识别**：打开系统「设置 → 通用 → 键盘 → 听写」，打开听写，并启用「简体中文 - 拼音」键盘（普通话，中国大陆）。再在「设置 → 通用 → 键盘 → 听写语言」里下载普通话（中国大陆）。没下好时，离线识别会失败，老人会看到「请让爸妈看看手机」。
3. **美式英语声音**：打开「设置 → 辅助功能 → 朗读内容 → 声音」，语言选英语（美国），下载增强或高品质声音。回到 Echo 的爸妈区可以刷新并试听。播放英文会先慢、再正常。
4. **字号**：打开「设置 → 辅助功能 → 显示与文字大小 → 更大字体」，把字号调大。老人这一页的英文、中文和按钮会跟着变大，最小也不低于 20 点。
5. **引导式访问**（只有这台 XS 专门给 Echo 用时才需要）：「设置 → 辅助功能 → 引导式访问」。老人的日常手机不要锁死。
6. **模型（可选）**：爸妈区选择 DeepSeek 或小米 MiMo，长按进入后点「填写 API Key」，用设备密码打开那一页再粘贴 Key。阅读说明后打开一次性同意。不同意就永远不会发送文字，对不上的句子留给晚上补。

卸载会删掉本机句子和录音。钥匙串里的 API Key 可能还在，重装后如果还显示「已有 Key」，到那一页删掉即可。家庭数据不进 iCloud 备份。

## 句库

第一次打开会放进大约 80 句日常短句（吃饭、洗澡、穿衣、出门、玩具、睡觉、安全和起居），中英文都是为这个 App 写的，不是科林斯例句，也不是词频表。它们算已经确认，爸妈可以改、可以删。仓库里没有孩子的名字、家庭录音或家庭私有句库。

## 数据

- 资料库版本现在是 **2**。版本 1 会在打开或恢复时迁过来：已确认的旧句子复制进句库，草稿仍待确认，不会因为版本号对不上就打不开。比 2 更新的包会拒绝，不会猜。
- 播放只追加一份小的使用记录，不再每次把整个库重写一遍。使用记录按天合并，每条最多留下最近 24 天，所以不会把 10 万条上限撑满后让 App 再也存不进东西。退到后台时会把这些记录写进主库。
- 老人的原话文字和原录音、孩子的跟读，都只存在手机本地，和别的录音用同一套删除、导出规则。
- 导出文件是未加密 JSON。分享完就从 App 里删掉。

## 怎么算做成

在真的厨房里让老人说 30 句。播出来的英文里，意思对的至少要有 80%。不到的话，先把句库缩小、按场景分开匹配，不要换识别引擎。步骤写在 [验收清单](docs/ACCEPTANCE.md)。

## 构建与测试

```text
Echo101/                 SwiftUI、录音、本机识别
Sources/EchoCore/        资料库、迁移、句库匹配、导出
Sources/EchoAPI/         DeepSeek / MiMo、Wi-Fi 或蜂窝开关、钥匙串
Tests/                   核心与模拟网络测试
Echo101UITests/          模拟器上的一页流程；不打开麦克风，不访问网络
```

没有第三方运行时依赖。Swift 6。iOS 最低 17。

```sh
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer \
swift test --disable-sandbox --scratch-path /tmp/echo101-tests
```

GitHub Actions 的 **Echo checks**（macOS 15，Xcode 16.4）会跑单元测试、设计色检查、无签名 `build-for-testing` 和模拟器 UI 测试。本仓库在 Linux 上不能编译 iOS。

用 Xcode 打开 `Echo101.xcodeproj`，选 Echo101，用你自己的免费 Apple ID 签名，装到 iPhone。不要把开发团队 ID 写进仓库。
