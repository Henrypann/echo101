# Echo · 验收清单

最低系统 iOS 17。安装方式是 Xcode 免费 Apple ID，经 USB 装到 iPhone XS。不使用 App Store 或 TestFlight。

自动检查以当前 PR 上的 GitHub Actions「Echo checks」为准。下面的家庭项必须在真机上勾选，模拟器不能代替。

## 厨房 30 句

在真实厨房里，让爷爷或奶奶说 30 句平时会说的话。

- 通过：播出来的英文里，至少 80% 意思是对的。
- 不通过：缩小句库，或按场景分组，不要换成另一套识别器。

## 真机还要听和看

- [ ] 飞行模式下，普通话（中国大陆）设备端识别能用；没下载听写资源时，会说「请让爸妈看看手机」，并在爸妈页留下待处理事项。
- [ ] 说一句：点一下开始、再点一下停止；开始和停止都有短提示音和中等震动；安静约 3 秒自己停；最长约 20 秒。
- [ ] 美式英语先慢读一遍，再正常读一遍。点句子里的一个词，只读那个词，并在读到时用强调色加粗。
- [ ] 「单词」点一行，大约 150 毫秒内出声，没有转圈。杭州条目在 XS 上逐条听过，读错的已写入 JSON 的 `ipa`。
- [ ] 第一次要麦克风和语音识别权限时，系统弹窗不会把录音打断掉。
- [ ] 孩子跟读约 10 秒，不打分；结束后大星星和「录好了」约 1 秒。单词页的小星星下次打开还在，也不会被扣掉。
- [ ] 导出 → 删除 App → 重装 → 恢复。分享后的 `.echo101` 副本已从 App 里删掉。
- [ ] 免费签名约 7 天后，重新签名覆盖安装，Bundle ID 仍是 `com.henrypann.echo101`。
- [ ] 离开超过 10 分钟再回来，停在「说一句」，爸妈页重新锁上。离开这个标签也会重新锁上。
- [ ] 爸妈页按住 3 秒才进入；标签上没有红色数字。API Key 才要面容或密码。
- [ ] 没有通知权限弹窗。没有连胜、爱心、经验、排行榜或发音打分。

## 自动测试应覆盖

- 词表能解析；每条都有英文、中文、英文例句、中文例句；只有一个置顶分类，并且排在最前。
- 句库优先；没有够好的匹配才准备问模型；没同意或没网时只记下待确认；未确认的句子不进句库、不进轮换。
- 版本 1 的库和备份能迁到版本 2；更新的版本被拒绝。
- 导出副本在分享结束和再次启动时被删掉。
- 使用记录有上限，播放不会整库重写。
- 界面：默认是「说一句」；能打开「今天」；「爸妈」要按住约 3 秒，离开后再锁上；「单词」能打开杭州和一条词的详情。

家庭验收结论：**待真机勾选**。
