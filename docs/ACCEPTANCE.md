# Echo · 验收清单

版本：**v0.3.0（build 3）**。最低 iOS 17。只给自己家用，免费 Apple ID 经 Xcode 安装。不使用 TestFlight，也不上架。

自动测试证明资料库、迁移、匹配和模拟器上的页面能跑。下面这些必须在 iPhone XS 上由家里的人点过，才算这条链路做成。

## 厨房 30 句

在真的厨房（或老人平时带孩子的地方）让老人说 30 句眼前正在发生的事。事先下载好普通话（中国大陆）离线语音。

- 通过：播出来的英文里，**意思正确的至少 24 句（80%）**。
- 不通过：先缩小句库，或按场景分开匹配。不要换成别的识别引擎，也不要打开云端识别。

意思正确是指孩子听到的那句英文，和老人想说的是同一件事。原话和中文意思对不上时，老人应能看出来并点「再说一遍」。

## 爸妈还要在 XS 上核对

- [ ] 麦克风和语音识别第一次弹出时，允许之后不用再按第三下才开始录。
- [ ] 没装普通话离线语音时，出现「请让爸妈看看手机」，爸妈区能看到待处理项。
- [ ] 安静约 3 秒自动停止；最长大约 20 秒。
- [ ] 「播放英文」先慢后正常，用的是美式英语声音。
- [ ] 「孩子跟读」大约 10 秒，出现「录好了」，不打分，录音能在爸妈区回放。
- [ ] 句库对不上、且没有同意或没有网时，出现「这句先记下了，爸妈晚上补英文」，晚上能补上并确认进句库。
- [ ] 模型句子在确认前可以听，但不会出现在句库里。
- [ ] 长按右上角「爸妈」约 3 秒进入；Face ID 只在填写 API Key 时出现。
- [ ] 切到后台再回来，停在老人这一页。
- [ ] 导出（含录音）→ 删掉 App → 用同一 Bundle ID 重装 → 从文件 App 恢复。内置例句可以被这份恢复包替换。
- [ ] 免费签名满 7 天后，重新用 Xcode 装上，数据还在。
- [ ] 超过 7 天没有导出时，爸妈区有提醒；老人这一页没有弹窗。

## 自动测试覆盖

- 句库优先；对不上且允许模型时才准备去问模型；不允许时保存为待补句。
- 未确认的生成句不进句库、不进轮换；爸妈确认后才进入。
- 版本 1 的本机库和恢复包迁到版本 2；更新的版本被拒绝。
- 导出副本在分享删除接口和下次启动时清掉，不跟着符号链接删到外面。
- 播放不重写整个库；使用记录按天合并并封顶，之后仍然可以写入。
- 模拟器 UI：一页、没有标签栏、长按「爸妈」、同意和蜂窝默认关闭、导出提醒、待确认句子确认后不再待确认。UI 测试不打开麦克风，不访问网络。
